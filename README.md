# Bloombal

Marketing landing page for Bloombal — a static site promoting Two-Factor Knowledge Validation for educational institutions.

This project was copied from the Perspective Mind AI landing page and rebranded.

## Local development

```bash
npm install
npm start
```

`webpack-dev-server` serves from `dist/` and hot-reloads `src/`.

Production build (writes to `dist/`, then copies to the repo root for GitHub Pages):

```bash
npm run build
```

Edit files under `src/` only. Put images in `src/img/` and videos in `src/videos/`.
